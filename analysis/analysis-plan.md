# Quantitative Analysis Plan v0.1

Status: working draft. Requires supervisor review before pre-registration. The qualitative
strand (interviews) has its own analysis approach and is out of scope for this document.

Software: R (lavaan/seminr) or Python (semopy); final choice at pilot stage. All analysis
code will be version-controlled in this directory alongside the power analysis.

---

## 0. Sample size

See [sample-size-memo.md](sample-size-memo.md), generated by `power_analysis.py`.
Planning target: N >= 200 analysable responses; assumptions to be revisited after the
pilot (n = 20).

## 1. Data screening

1. Remove non-consenting, screened-out (S1 = No), and straight-lined responses
   (zero variance across Sections A-E).
2. Completion-time floor: responses below one-third of the pilot median flagged and
   inspected before exclusion. Exclusion counts reported in full.
3. Missingness: item-level missingness reported; "Not applicable" treated as missing,
   not midpoint. If missingness exceeds 5% on any construct, MCAR check (Little's test)
   before choosing between FIML and listwise deletion.
4. Distributions: skew/kurtosis per item; 5-point Likert items treated as ordinal in
   the measurement model (WLSMV / polychoric) unless distributions justify otherwise.

## 2. Reliability and validity (deployed multi-item instrument)

1. Internal consistency: Cronbach's alpha and composite reliability (CR) per construct;
   threshold .70, with the single-item v0.1 constructs flagged as the known weakness
   they are (survey draft, "Known weaknesses" item 1).
2. Convergent validity: average variance extracted (AVE) >= .50 per construct.
3. Discriminant validity: Fornell-Larcker and HTMT (< .85); particular attention to
   Q9/Q10 (risk perception vs trust fragility), which the survey draft already flags
   as potentially loading on one factor.

## 3. Measurement model (CFA)

1. Specify the 8-construct measurement model from the survey's construct mapping.
2. Fit criteria reported together, never selectively: chi-square (with df), CFI/TLI
   (>= .95 good, >= .90 acceptable), RMSEA (<= .06), SRMR (<= .08).
3. Modifications only with theoretical justification; every freed parameter reported.
4. Measurement invariance (configural/metric/scalar) across clinical vs managerial
   roles before any subgroup comparison is interpreted.

## 4. Structural model

Estimated with PLS-SEM (rationale: sample-size feasibility, see memo section 2;
formative potential of facilitating conditions to be assessed at pilot).

| Step | Model | Answers |
|---|---|---|
| 4.1 | Trust antecedents (reliability, credibility, value, risk) -> trust | RQ1a, H1a |
| 4.2 | AI literacy as moderator of antecedent -> trust paths | H1a (moderation) |
| 4.3 | Explainability (verifiable Q12 vs narrative Q13) -> trust -> intention; direct path tested for mediation | RQ2a, RQ2b, H2b |
| 4.4 | Q12 vs Q13 path-coefficient contrast | H2c |
| 4.5 | Facilitating conditions / governance (Q14) and institutional trust transfer (Q11) -> intention; interaction with policy posture | RQ3a |
| 4.6 | Shadow-use (S2) as a categorical outcome: trust x restrictive policy -> unsanctioned use (logistic) | RQ3b, H3a |

Bootstrapped (5,000 resamples) confidence intervals for all path coefficients and
indirect effects; no p-value reported without its interval.

## 5. Sensitivity and robustness

1. Re-run the structural model excluding flagged-but-retained responses.
2. Common-method variance: full collinearity VIFs (threshold 3.3); if exceeded,
   marker-variable check.
3. H1b (trust fragility / negativity asymmetry) tested as a planned contrast on Q10
   by reported hallucination experience; exploratory if the experience item is not
   added in v0.2 as intended.

## 6. Reporting commitments

- Every hypothesis (H1a-H3b) reported against its result, including nulls.
- Effect sizes with intervals throughout; no claim rests on significance alone.
- Subgroups below the powered threshold (memo section 3) reported descriptively only.
- Analysis code and de-identified aggregates published in this repository, subject to
  the ethics protocol in [../ethics/ethics-checklist.md](../ethics/ethics-checklist.md).
